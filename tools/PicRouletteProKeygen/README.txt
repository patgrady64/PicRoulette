PicRoulette Pro Keygen
======================
1. Install Python 3.
2. In this folder run: pip install -r requirements.txt
3. Run: python picroulette_pro_keygen.py
4. Copy the Installation ID from PicRoulette into the keygen.
5. Generate the code and send only the activation code to the user.

IMPORTANT: picroulette_private_key.pem is the secret that can create valid Pro codes.
Keep it private and never ship it inside the Android app or publish it in a public repository.
Back it up somewhere safe. If it is lost, this version of PicRoulette cannot generate matching codes.
